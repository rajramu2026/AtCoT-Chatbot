# Atlantic Coast Tours — Simple Gemini Chatbot

This is the simplified version of the project. It keeps the existing GitHub Pages user interface and uses:

- **GitHub Pages** for `index.html`, `styles.css` and `app.js`;
- **Google Apps Script** as a very small secure bridge;
- **Gemini 3.5 Flash-Lite** as the genuine language-model brain;
- the assigned Google Sheet, fetched again for every question.

No Vercel account or Node project is required.

## Files

```text
GitHub repository root/
├── index.html
├── styles.css
├── app.js
├── Code.gs
└── README.md
```

`Code.gs` is kept in GitHub as part of the submitted source, but it must also be pasted into a Google Apps Script project and deployed as a Web App.

## Why Google Apps Script is needed

Putting the Gemini key directly in `app.js` would expose it publicly. Apps Script stores the key in Script Properties and makes the Gemini request on Google's servers. The GitHub Pages site calls the Apps Script Web App using JSONP, which avoids cross-origin restrictions without needing Vercel.

## One-time Google Apps Script setup

1. Open Google Apps Script and create a new standalone project.
2. Delete the sample code in `Code.gs`.
3. Paste the supplied `Code.gs` file into the editor and save it.
4. Open **Project Settings**.
5. Under **Script Properties**, add:

   | Property | Value |
   |---|---|
   | `GEMINI_API_KEY` | Your Google AI Studio API key |
   | `GEMINI_MODEL` | `gemini-3.5-flash-lite` |

6. Do not paste the key into GitHub, `app.js` or `Code.gs`.
7. Select **Deploy → New deployment**.
8. Select **Web app**.
9. Configure:
   - Execute as: **Me**
   - Who has access: **Anyone**
10. Select **Deploy** and approve the requested permissions.
11. Copy the Web App URL ending in `/exec`.

## Connect GitHub Pages to Apps Script

Open `app.js` and find:

```javascript
APPS_SCRIPT_URL: "PASTE_YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE",
```

Replace only the placeholder with the `/exec` URL copied from Apps Script:

```javascript
APPS_SCRIPT_URL: "https://script.google.com/macros/s/YOUR_DEPLOYMENT_ID/exec",
```

Do not put the Gemini API key on this line.

Upload `index.html`, `styles.css` and the edited `app.js` to the GitHub repository root. Commit the changes and wait for GitHub Pages to redeploy.

## How it meets the requirements

### Genuine language model

Every question is sent to Gemini 3.5 Flash-Lite. There are no JavaScript keyword-response tables and no scripted business answers.

### Off-topic proof

Test:

1. `Can I order food?`
2. `Can you write a poem about Mars?`
3. `What is 17 multiplied by 23?`
4. `Can you recommend a laptop?`

Gemini should naturally explain that it can only assist with Atlantic Coast Tours and redirect the visitor to a tour-related question. Wording can vary because the answer is generated by a language model.

### Fresh Google Sheet data

`Code.gs` performs a new Google Sheet CSV export request inside every customer question. It uses:

- a new timestamp parameter;
- `Cache-Control: no-cache, no-store`;
- no saved tour records;
- no hardcoded tour rows, prices, slots or offers.

The tour data exists only temporarily while the current question is being processed.

### Sheet-reading tests

Run:

1. `List the current tours and their IDs.`
2. `What special offers are available?`
3. `Which tours have slots this week?`
4. Copy a returned tour ID and ask for all its details.

For a specific tour, Gemini is instructed to show:

- Tour ID
- Tour name
- Category
- Location
- Meeting point
- Exact price
- Duration
- Capacity
- Availability
- Slots available this week
- Special offer
- Description

## Fresh-data demonstration

1. Ask for a tour's price or slots.
2. Change the value in the Google Sheet.
3. Ask the same question again.
4. Check the timestamp displayed beneath the chatbot answer.

The second question triggers a new Sheet request and should reflect the newly saved value.

## Updating Apps Script later

After changing `Code.gs`:

1. Open **Deploy → Manage deployments**.
2. Edit the existing Web App deployment.
3. Select **New version**.
4. Deploy the new version.

Normally, the `/exec` URL remains the same.

## Troubleshooting

### “Setup required”

The Apps Script `/exec` URL has not been pasted into `CONFIG.APPS_SCRIPT_URL` in `app.js`.

### Apps Script returns an error

Check that:

- `GEMINI_API_KEY` exists in Script Properties;
- the key is active in Google AI Studio;
- the Web App is deployed with access set to **Anyone**;
- the URL in `app.js` ends in `/exec`;
- the assigned Google Sheet CSV export is accessible.

### The old code still appears

Hard-refresh the GitHub Pages site or open it in a private browser window after committing the files.
